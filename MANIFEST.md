# Paquete de entrega NYC311 — Fase 3

La carpeta que se presenta al evaluador es `fase-3/`. El resto del repositorio conserva el linaje académico de las fases anteriores.

## Entregables principales

- `fase-3/Documento_Fase3.docx`: documento académico final editable.
- `fase-3/Documento_Fase3.pdf`: copia de revisión del documento.
- `fase-3/Presentacion_Fase3_NYC311.pptx`: pitch deck editable para la defensa.
- `fase-3/Presentacion_Fase3_NYC311.pdf`: copia para proyectar, si está disponible.
- `fase-3/powerbi/NYC311_Fase3_Final.pbix`: informe ejecutable de Power BI.
- `fase-3/powerbi/fuente_pbip/`: fuente PBIP/PBIR/TMDL versionable del informe.
- `fase-3/guion_defensa.md`: apoyo privado para la exposición oral.

## Linaje conservado

- `fase1/`: SQL, SSIS, modelo dimensional y cubo OLAP.
- `fase2/`: notebooks reproducibles, código e informes de minería.
- `referencias/`: premisa, documentos académicos previos y referentes visuales.

No se presentan como entregables las versiones descartadas de PBIX, capturas históricas, renders de QA, carpetas temporales ni rutas internas usadas durante la construcción.
