# DMD NYC311 Fase 3

Repositorio consolidado de las fases del proyecto académico NYC311.

## Estructura

- `fase1/`: Datawarehouse, modelo dimensional y cubo OLAP.
- `fase2/`: notebooks reproducibles y resultados genuinos de minería.
- `fase-3/`: Power BI, documento final, presentación y guion de defensa.
- `referencias/`: premisa, documentos de referencia y fuentes de diseño.
- `qa/`: comprobaciones y reportes de revisión, no entregables principales.

La carpeta `fase-3` contiene el paquete que se presenta. Los archivos temporales, renders y versiones descartadas quedan fuera del paquete final o en `qa`.
