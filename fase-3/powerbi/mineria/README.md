# Salidas de minería usadas por Fase 3

El archivo `resumen_clusters_f2.csv` es una salida auxiliar histórica del experimento K-Means de Fase 2. La ejecución reproducible actual calcula 481 combinaciones elegibles sobre el rango completo disponible y no depende de ese CSV.

La fuente canónica de los datos que consume Power BI es `DW_NYC311.bi.vw_solicitudes_segmentadas`. El PBIX conserva además las solicitudes fuera de perfil como `Sin perfil K-Means`.
